# 🕵️ Кто шпион?

Telegram-бот для игры **«Кто шпион?»** в групповых чатах.

Игроки получают секретное слово, кроме одного игрока — **шпиона**. Шпион получает только случайную подсказку и должен по ответам остальных понять, какое слово загадано, не выдав себя.

---

## 🎮 Как работает игра

В игре:

- минимум **4 игрока**;
- максимум **15 игроков**;
- один игрок случайно становится шпионом;
- остальные получают одинаковое секретное слово;
- шпион получает случайную подсказку к этому слову;
- игроки по очереди дают свои ответы;
- после этого начинается голосование;
- каждый игрок выбирает того, кого считает шпионом;
- бот определяет победителя.

### 🏆 Кто побеждает?

**Мирные игроки побеждают**, если по итогам голосования находят настоящего шпиона.

**Шпион побеждает**, если игроки голосуют не за него.

Если возникает ничья между несколькими игроками, побеждает шпион.

# 🤖 1. Создание Telegram-бота

Для работы нужен Telegram-бот.

Создать его можно через официального бота Telegram — **@BotFather**.

Открой Telegram и найди:

**@BotFather**

Затем отправь:

```text
/newbot
```

BotFather попросит:

1. название бота;
2. username бота.

Username должен заканчиваться на:

```text
bot
```

Например:

```text
my_spy_game_bot
```

После создания BotFather выдаст токен примерно такого вида:

```text
123456789:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

### ⚠️ Никому не показывай токен

Токен даёт доступ к управлению ботом.

Не отправляй его:

- другим людям;
- в Telegram-чаты;
- в GitHub;
- в README;
- в скриншотах;
- в публичный код.

Если токен случайно стал публичным — создай новый через BotFather.

# 🎮 7. Как начать игру

После команды:

```text
/spy
```

бот создаст лобби:

```text
🕵️ КТО ШПИОН?

Игроки: 0/15

Пока никто не присоединился.

Минимум для старта: 4

[➕ Присоединиться]
[🚀 Начать игру]
```

### Шаг 1 — игроки присоединяются

Каждый участник нажимает:

```text
➕ Присоединиться
```

Бот покажет список участников.

Например:

```text
Игроки: 5/15

1. Артём
2. Дима
3. Саша
4. Максим
5. Никита
```

---

### Шаг 2 — запуск

Когда собралось минимум 4 человека, **создатель игры** нажимает:

```text
🚀 Начать игру
```

Бот случайным образом:

- выбирает слово;
- выбирает одного шпиона;
- перемешивает порядок игроков.

---

# 🕵️ 8. Как получают роли

Каждому игроку бот отправляет личное сообщение.

### Обычный игрок получает:

```text
🤫 ТВОЁ СЕКРЕТНОЕ СЛОВО

Пицца

Не показывай его другим игрокам!
```

### Шпион получает:

```text
🕵️ ТЫ ШПИОН!

Твоя подсказка:
Её часто заказывают вечером.

Попробуй понять, какое слово знают остальные,
и не выдай себя.
```

Шпион **не знает секретное слово**.

---

# 💬 9. Обсуждение

Бот случайным образом выбирает первого игрока.

Например:

```text
🗣 Первый говорит:

Артём
```

Артём говорит какую-нибудь ассоциацию с секретным словом.

Например, если слово:

```text
Пицца
```

он может сказать:

```text
Итальянское
```

После ответа он нажимает:

```text
✅ Я сказал
```

После этого ход переходит следующему игроку.

---

# 🗳 10. Голосование

Когда все игроки высказались, бот показывает:

```text
🗳 ГОЛОСОВАНИЕ

Выберите игрока, которого считаете шпионом.

[Артём]
[Дима]
[Саша]
[Максим]
[Никита]
```

Каждый игрок выбирает одного человека.

За себя голосовать нельзя.

Повторно проголосовать нельзя.

---

# 🏆 11. Результат

После того как проголосовали все участники, бот подсчитывает голоса.

### Если нашли шпиона:

```text
🎉 МИРНЫЕ ПОБЕДИЛИ!

Игроки вычислили шпиона: Саша

🕵️ Шпион: Саша
🤫 Слово: Пицца
```

### Если ошиблись:

```text
🕵️ ШПИОН ПОБЕДИЛ!

Игроки выбрали: Максим

Но настоящий шпион был: Саша

🤫 Слово: Пицца
```

### Если ничья:

Шпион автоматически побеждает.

# 📝 13. Добавление новых слов

Все слова находятся в:

```text
words.py
```

Каждый элемент имеет такой формат:

```python
(
    {
        "word": "Самолёт",
        "spy_hints": [
            "Он связан с путешествиями",
            "Обычно находится довольно высоко",
            "Внутри много пассажиров",
            "Его часто ждут в определённом месте",
            "У него есть крылья",
        ],
    },
)
```

Чтобы добавить новое слово, просто добавь ещё один такой блок:

```python
(
    {
        "word": "Кинотеатр",
        "spy_hints": [
            "Там обычно довольно темно",
            "Туда приходят ради большого экрана",
            "Там продают еду и напитки",
            "Там стараются не разговаривать громко",
            "Перед началом приходится ждать",
        ],
    },
)
```

Количество подсказок может быть любым.

Например:

```python
"spy_hints": [
    "Подсказка 1",
    "Подсказка 2",
    "Подсказка 3",
    "Подсказка 4",
    "Подсказка 5",
]
```

Бот случайно выберет **одну подсказку именно для выбранного слова**.

Например:

```python
chosen_item = random.choice(WORDS_DB)

secret_word = chosen_item["word"]

spy_hint = random.choice(chosen_item["spy_hints"])
```

Сначала выбирается:

```text
Пицца
```

А затем случайно одна из подсказок:

```text
Её обычно делят на кусочки
```

Подсказка от другого слова шпиону не попадётся.

# ⚠️ Важные моменты

### Бот должен быть запущен

Если ты закроешь программу:

```text
Ctrl + C
```

бот перестанет отвечать.

### Игры хранятся в памяти

Сейчас информация об играх хранится в обычном Python-словаре:

```python
games = {}
```

Поэтому после перезапуска бота текущие игры исчезнут.

Для небольшой игры это нормально.

### Игрок должен открыть бота в личке

Чтобы бот смог отправить человеку секретное слово или роль, человек должен сначала открыть бота и нажать:

```text
Start
```

Код проверяет отправку ролей перед началом игры. Если кому-то сообщение отправить нельзя, игра не начинается.

# 🔒 Безопасность токена

Никогда не добавляй настоящий токен в GitHub.

Плохо:

```python
TOKEN = "123456789:AAxxxxxxxx"
```

если этот файл публикуется в открытом репозитории.

Лучше использовать переменную окружения:

```python
import os

TOKEN = os.getenv("BOT_TOKEN")
```

А перед запуском установить:

Linux/macOS:

```bash
export BOT_TOKEN="твой_токен"
```

Windows PowerShell:

```powershell
$env:BOT_TOKEN="твой_токен"
```

После этого:

```bash
python bot.py
```

# 🐛 Если бот не запускается

### Ошибка `ModuleNotFoundError: No module named 'aiogram'`

Установи зависимости:

```bash
pip install -r requirements.txt
```

---

### Бот запускается, но не отвечает

Проверь:

1. Правильный ли токен.
2. Запущен ли `bot.py`.
3. Добавлен ли бот в группу.
4. Написал ли ты `/spy`.
5. Нет ли другого экземпляра этого же бота, который уже использует токен.

---

### Игрок не получает роль

Игрок должен:

1. открыть бота в Telegram;
2. нажать **Start**;
3. вернуться в группу;
4. снова запустить игру.
